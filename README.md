# Simulador de Crédito com Machine Learning

## Objetivo

Aplicação desktop desenvolvida em Python
para simular uma análise de solicitação de
empréstimo utilizando Random Forest.

## Tecnologias

- Python
- Scikit-learn
- Pandas
- CustomTkinter
- Joblib

## Funcionalidades

- Cadastro de proposta
- Análise utilizando ML
- Probabilidade estimada
- Histórico das solicitações
- Persistência do modelo
